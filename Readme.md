PROJECT OBJECTIVES
The main objectives of the NISCO LMS are to:
•	Digitize student management.
•	Digitize academic management.
•	Simplify course enrollment.
•	Manage student attendance.
•	Manage assignments and assessments.
•	Manage examinations and results.
•	Calculate GPA/CGPA.
•	Monitor academic progress.
•	Manage student payments.
•	Integrate online payment facilities.
•	Provide dashboards and reports.
•	Manage the complete student lifecycle.
•	Support graduation/pass-out processes.
•	Reduce manual administrative work.
•	Provide centralized academic information.
•	Provide secure role-based access.
•	Provide a scalable technical foundation for future development.

INITIAL WORKING LMS – MAXIMUM 12 DAYS
4.1 Important Clarification
The 12-day period is an initial development period, not a requirements-analysis period.
After receiving the customer's initial requirements, the development team will develop a minimum/core working version of the LMS within a maximum target of 12 days.
The purpose is to make the LMS functional at an early stage instead of waiting until the entire system is completed.

•	Basic enrollment

•	Initial React frontend
•	API integration

4.3 Purpose of Initial Development
The initial working version allows:
